### Probe SQL (service role / SQL Editor) — inventario, no sustituye UI

```sql
SELECT s.slug, s.activo,
  (SELECT COUNT(*) FROM citas c WHERE c.salon_id = s.id) AS citas,
  (SELECT COUNT(*) FROM clientas cl WHERE cl.salon_id = s.id) AS clientas
FROM salones s
WHERE s.slug IN (
  'salon-tutis',
  'galaxy-barberia-infantil',
  'gota-prueba-s13',
  'belleza-luna'
)
ORDER BY s.slug;
```
